# Relogio Digital com JavaFX

Aplicacao desktop que exibe um relogio digital em tempo real, praticando atualizacao de interface, tempo e componentes visuais em JavaFX.

## Repositorio

[relogio-digital](https://github.com/p-rcorreia/relogio-digital.git)

## Objetivo

Criar um relogio digital funcional, com exibicao de hora atual e atualizacao automatica.

## Conceitos praticados

- JavaFX
- API de data e hora
- Atualizacao periodica da interface
- Layouts e estilização com CSS
- Organizacao de uma aplicacao desktop simples

## Funcionalidades planejadas

- Exibir hora atual
- Atualizar a cada segundo
- Exibir data atual
- Aplicar estilo visual com CSS
- Opcional: alternar formato 12h/24h
